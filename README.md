# Documentation Centre

Responsive static website for Documentation Centre, cooperative business guidance in Bihar and Jharkhand.

## Project overview

This repository contains a modern, responsive static website designed to help visitors contact Documentation Centre for cooperative business guidance and documentation support in Bihar and Jharkhand.

## Files included

- `index.html` — main website entry point
- `styles.css` — complete responsive styling
- `script.js` — navigation, animations, and WhatsApp enquiry form handling
- `assets/favicon.svg` — favicon
- `robots.txt` — search engine instructions
- `sitemap.xml` — sitemap for search indexing
- `.github/workflows/deploy-pages.yml` — GitHub Pages deployment workflow

## Publishing on GitHub Pages

1. Push the repository to GitHub.
2. Open the repository on GitHub.
3. Go to Settings → Pages.
4. Under Source, select "GitHub Actions".
5. Push to the `main` branch and the workflow will deploy the site.

The project is ready for free GitHub Pages hosting with no backend required.
